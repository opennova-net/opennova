# Music Editor Workspace

One screen: a state map with an always-visible States sidebar, a breadcrumb
trail with back/forward (Alt+Left / Alt+Right), and per-state blueprints where
statements edit inline on their nodes. Open paired .sbf + .bin files from the
configured resource root; drag tracks from the Tracks dock onto a state, press
Start to hear changes live. Variables can be given friendly display names
(stored in a .music_profile.json sidecar; the script file keeps its VarXX
tokens).
