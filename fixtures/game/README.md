# Menu contract fixtures

These authored menu documents and string tables exercise the engine's menu parser,
navigation, options, player and armory bindings. They are deliberately independent
of the downloadable OpenNova content repository. Change them when a menu contract
test needs a new shape; they are not a content release snapshot to synchronize.

Godot tests stage them over generated runtime fixtures, with synthetic font and
image data. No mission binary, terrain, model, music or production texture belongs here.
The main menu retains the `PLAY_RETAIL` and `CHANGE_FOLDER` controls so the
shell's retail-install picker can be tested without a content checkout.

The two small shader templates are serializer goldens generated by the editor's
blank factory. Native editor tests compare the factory's output with these files
and check the renderer tags; they are not downloadable game assets.

The four tiny WAC samples retain the original compiler's existing listing witnesses
when the game projects move out of the engine tree.
